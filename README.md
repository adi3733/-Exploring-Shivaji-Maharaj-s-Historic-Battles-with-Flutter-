# 🚩 Shivaji Maharaj Battles App

A simple and visually engaging **Flutter mobile application** that presents major battles led by *Chhatrapati Shivaji Maharaj* using historical images and dates.

---

## 📱 App Preview

Displays one battle at a time with:
- 📷 Historic image
- 🗓️ Battle name and date
- ➡️ Button to view next battle

---

## ⚙️ Tech Stack

- **Flutter** 💙
- **Dart**
- Stateless & Stateful Widgets
- Network Images via `Image.network`
- Material Design

---

## 📌 Features

- Swipe through **4 key battles**:
  - Battle of Pratapgad (10 May 1659)
  - Battle of Pavan Khind (13 July 1660)
  - Battle of Umberkhind (2 February 1661)
  - Sacking of Surat (5 January 1664)
- Organized data using `List<Map<String, String>>`
- Clean and responsive layout using `Column`, `Container`, and `ClipRRect`
- Navigation handled with `setState()` and index update
